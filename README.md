# Permission

A short poem about agency: the power to ask and to be given.

A speaker places a sparrow in someone's open hands and asks them not to
close them. The bird's heart beats against a lifeline, the holder feels the
ache of not keeping it, and then the bird rises. The hands stay open — the
gift was never the bird, but the right to open them.

## Run

```sh
python3 main.py
```

This writes the poem to `/output/entry.txt` (or to
`$MAKEFUN_OUTPUT_DIR/entry.txt` when that variable is set).
